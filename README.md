# Università

Questa repository raccoglie appunti, esercizi, dispense, riassunti ed elaborati preparati durante il mio percorso universitario in informatica.

L'obiettivo è avere un archivio ordinato del materiale usato per studiare, ripassare e preparare esami, sia della triennale sia della magistrale.

## Struttura

- `Triennale/`: materiale relativo al corso di laurea triennale, organizzato per anno e insegnamento.
- `Magistrale/`: appunti e risorse della laurea magistrale, con documenti organizzati per corso.

All'interno delle cartelle si trovano principalmente file LaTeX, appunti in formato testuale, esercizi svolti, dispense e alcune risorse di supporto come immagini o materiali per i calcoli e gli schemi.

## Contenuti

La repository include, tra le altre cose:

- appunti delle lezioni;
- esercizi ed esempi svolti;
- riassunti e formulari;
- materiali per la preparazione agli esami;
- documenti LaTeX per la stesura di relazioni e note organizzate.

## Nota

La repository è pensata soprattutto come archivio personale di studio, quindi la struttura può cambiare nel tempo in base ai corsi seguiti e al materiale aggiunto.
